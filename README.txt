YOUR BIRTHDAY WEBSITE 💗

FILES
- index.html: website content
- style.css: colours, layout and decorations
- script.js: envelope / ENTER interaction
- assets/: put your own photos and videos here

ADD YOUR PHOTOS
1. Choose 3 photos of him.
2. Put them inside the assets folder.
3. Rename them exactly:
   photo1.jpg
   photo2.jpg
   photo3.jpg
4. If your photo is PNG, either convert it to JPG or change the matching
   image filename in index.html.

ADD YOUR VIDEOS
1. Put up to 2 MP4 videos inside the assets folder.
2. Name them:
   video1.mp4
   video2.mp4
3. If you do not want a video in one of the slots, remove that video-card
   block from index.html.

CHANGE THE WORDS
Open index.html and edit the birthday wish and letter text.
You can change "My Love" to the nickname you use for him.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a new repository.
2. Give it a name, for example: birthday-surprise.
3. Upload index.html, style.css, script.js, README.txt and the assets folder.
   Make sure index.html is in the main/root folder, not inside another folder.
4. Open the repository's Settings.
5. Select Pages from the left menu.
6. Under "Build and deployment", choose "Deploy from a branch".
7. Choose branch "main" and folder "/ (root)", then Save.
8. Wait a few minutes. GitHub will show your free website link in the Pages section.

IMPORTANT
The website is static and does not need a server or database.
Keep the repository public if you are using GitHub Pages on the free plan.
Anyone with the link can view the website. Do not upload anything private.
Large videos may make the website slow or exceed GitHub's recommended file
size. Keep videos short and compressed.
